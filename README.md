# HMA Client

HMA Client is a launcher for Minecraft: Java Edition that makes the game more convenient to set up and play.

## What it does

- Sets up a ready-to-play environment in one click
- Keeps that environment up to date
- Lets you sign in with your own Microsoft account and launch the game

## Sign-in

HMA Client uses the standard Microsoft account sign-in. You need a Microsoft account that owns Minecraft: Java Edition.
Your sign-in is kept only on your own computer, and is sent only to Microsoft and Mojang services.

## Status

HMA Client is in early development and has not been released yet.
